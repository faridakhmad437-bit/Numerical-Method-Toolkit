# Numerical Methods Toolkit

Educational scientific-computing library implementing numerical algorithms from first principles.

## Algorithms

### Root finding
- Bisection
- Newton-Raphson
- Secant
- Fixed Point Iteration

### Numerical integration
- Composite Trapezoidal Rule
- Composite Simpson 1/3 Rule

### ODEs
- Euler
- Classical RK4

### Linear systems
- Gaussian Elimination with partial pivoting
- Jacobi Iteration
- Gauss-Seidel Iteration

### Interpolation
- Lagrange Polynomial
- Newton Divided Differences

### Robotics
- Multivariable Newton method
- Planar 2-link inverse kinematics

## Philosophy
Theory -> Implement -> Test -> Verify -> Measure -> Document -> Apply

This project is educational and does not attempt to replace mature numerical libraries such as SciPy.
